# ebp-diagnostico
Plataforma de diagnóstico rápido para distintos sectores de dónde "duele" el cambio climático y así tener una primer identificación de donde deberían implementarse medidas de adaptación y mitigación. La plataforma cruza con datos de amenazas de ARClim, Think Hazard. Además se basa en fuentes de CEPAL MMA, MinHacienda y UNDRR / CDRI para Chile.
